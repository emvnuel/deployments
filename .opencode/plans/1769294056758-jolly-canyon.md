# Plan: Create copilot-api Deployment

## Overview
Create a new deployment for `myawesomeapps/copilot-api:1.0` using the common-chart pattern, with secrets (`GH_TOKEN`, `API_KEY`) stored in a gitignored file.

## Files to Create

### 1. `copilot-api/values.yaml`
Main values file for the deployment:
- Image: `myawesomeapps/copilot-api:1.0`
- Container port: `4141`
- Ingress host: `llm.awesomeapps.cloud`
- TLS enabled with cert-manager
- Reference secrets via `envFrom` with `secretRef`

### 2. `copilot-api/secrets.yaml`
Kubernetes Secret containing:
- `GH_TOKEN`
- `API_KEY`
(Values to be filled in by user)

## Files to Modify

### 3. `.gitignore`
Add pattern to exclude copilot-api secrets:
```
copilot-api/secrets.yaml
```

## Deployment Structure
```
copilot-api/
├── values.yaml      # Common-chart configuration (tracked in git)
└── secrets.yaml     # Kubernetes Secret (gitignored)
```

## Deploy Command
```bash
# First apply the secrets
kubectl apply -f copilot-api/secrets.yaml

# Then deploy using common-chart
helm install copilot-api common-chart/ -f copilot-api/values.yaml
```

## Verification
1. Run `helm lint common-chart/` to validate chart
2. Run `helm template copilot-api common-chart/ -f copilot-api/values.yaml` to test rendering
3. Verify `copilot-api/secrets.yaml` is not tracked: `git status`
